cucumber - Fabric 1.21.4 client mod (needs Java 21 + Fabric API 0.119.2+1.21.4)
Build:  gradle build  -> build/libs/cucumber-1.0.0.jar -> .minecraft/mods
Or push this folder to GitHub: the Actions tab builds the jar (artifact "cucumber-jar").
Key:    O opens/closes the menu (rebind in Controls > cucumber). The bomb timer also shows on screen while the menu is closed.
Tabs:   Players (radius, armor, enchants, BOMB), Target (bomb any online nickname), Themes, Settings, About
Config: saved to .minecraft/config/cucumber.properties
Nametag: after a bomb goes off the player gets a custom nametag (HP, DMG, armor, enchants, ping). Toggle/clear in Settings.
